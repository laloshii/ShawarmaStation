# Shawarma Station

## التركيب

الواجهة الكاملة هي public/index.html. استخدميها بدل وثيقة HTML القديمة. لوحة الإدارة مستقلة على /admin/. إذا بدك تحافظي على موقعك كصفحة ترحيبية، احتفظي بصفحتك القديمة باسم landing.html والصقي محتوى integrate.html داخل body بعد الشريط العلوي. المقطع يعرض المينو داخل الصفحة مع رابط فتحه بحجم كامل. استخدميه على نفس النطاق بعد تشغيل الخادم. تجنبي تضمين index.html داخل نفسه، وأزيلي أقسام الطلب القديمة حتى لا يكون هناك سلّتان. عند الاستضافة على نطاق آخر استخدمي رابط الفتح بعنوان المينو الكامل فقط.

المشروع تطبيق Python 3.11+ قابل للاستضافة مع قرص دائم، وليس موقع HTML ثابتاً. من مجلد المشروع، على Linux أو macOS:

    python3 -m venv .venv
    . .venv/bin/activate
    python -m pip install -r requirements.txt
    python app.py setup
    python -m uvicorn app:app --host 127.0.0.1 --port 8000

اختاري كلمة مرور خاصة عند التهيئة. افتحي http://127.0.0.1:8000/ وللإدارة افتحي http://127.0.0.1:8000/admin/. لإعادة تعيين كلمة المرور أعيدي أمر setup، وهو يلغي الجلسات السابقة ويحتفظ بالمنتجات والطلبات. في Windows فعّلي البيئة بالأمر .venv\Scripts\activate بعد إنشائها.

## النشر

انشري التطبيق في جذر نطاق أو نطاق فرعي عبر reverse proxy مع HTTPS وشهادة صالحة. حددي STATION_ORIGIN بالأصل الحقيقي الكامل مثل https://menu.example.com قبل بدء الخادم. اربطي الخادم الداخلي بالعنوان المحلي فقط، وحددي في الوكيل حد الطلب 3 MB وثقي عناوين الوكلاء الذين يمررون عنوان الزائر فقط. ارفضي الطلبات ذات الطول غير المحدد واجعلي الوكيل يرسل Content-Length. حددي STATION_DATA بمسار خاص دائم خارج المجلد العام قبل أمر التهيئة وقبل التشغيل. ضمّني قاعدة SQLite في النسخ الاحتياطي عبر SQLite backup. قاعدة البيانات تشمل الصور والطلبات. لا تشاركي نسخة الإنتاج أو بيانات الدخول. لتشغيل المينو تحت مسار فرعي يلزم تعديل المسارات المطلقة أو إعداد توجيه مخصص.

## بيانات المينو وطريقة العمل

seed.json يحتوي لقطة من بيانات المينو العام بتاريخ 8 تشرين الثاني 2026 من https://brandstationsy.com/resturant-menu/index.html وواجهة القراءة التابعة لها. تُستورد أول مرة فقط. الإدارة الجديدة مستقلة عن نظام BrandStation، والطلبات التي يرسلها هذا المينو تسجل هنا. الاتفاق على توجيه رابط QR القديم أو زر المينو للنطاق المنشور يتم مع صاحب الموقع.

الأقسام الأصلية والأسعار بالليرة السورية. المشروبات بعد أقسام الطعام في العرض الكامل. نصوص الأصناف بالعربية كما نشرها المطعم. أدرجنا الغلاف والشعار الحاليين. صور الأصناف تُرفع من الإدارة، ولا تُستخدم الصور القديمة. ارفعي صورة JPEG أو PNG أو WebP بحد ٢ ميغابايت. فعّلي الإضافات المناسبة لكل صنف. يمكن تعديل أسعار الإضافات أو إضافة خيارات جديدة. حفظ صنف بعد فتحه من محررين مختلفين يكشف تعارض النسخ. الطلب الداخلي يطلب طاولة، والخارجي يطلب موقع التسليم أو الاستلام ورقم التواصل. المبلغ هو مجموع الأصناف والإضافات، دون رسوم أو عروض مفترضة. حالات الطلبات والتنبيهات تتحدث كل ٣٠ ثانية ويمكن تحديثها يدوياً. قائمة الإدارة تعرض آخر ١٥٠ طلباً. لتأكيد التركيب اختبري طلباً داخلياً واختبري تحديث السعر ورفع صورة ثم راجعي النتيجة بمتصفح آخر.
